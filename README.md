# AK 대학입시 상담 — 태권도학과 입시 분석

전국 **4년제 대학 · 전문대학 · 학점은행** 태권도 관련 학과 정보와 입시전형을 한눈에 보고,
내 성적·실기 경력을 단계별로 입력해 맞춤 입시 분석을 받을 수 있는 정적 웹사이트입니다.

## 기능
- **대학 찾기** — 유형(4년제/전문대/학점은행) · 지역 · 전형 유형 · 모집시기 필터, 검색
- **학과 상세** — 전형별 모집인원, 반영비율(막대 그래프), 실기 종목, 지원자격, 경쟁률·참고 입결, 출처
- **입시 분석(4단계)** — 희망 조건 → 성적(내신/수능) → 태권도 경력(품·단, 종목, 수련기간, 대회실적) → 진로
  → 전형별 적합도와 안정/적정/소신/도전 판정, 맞춤 원서 전략
- **비교** — 최대 4개 학과 나란히 비교
- **입시 가이드** — 연간 일정, 전형 유형, 실기 준비, 학점은행제 안내

## 데이터 수정
1. `data/fouryear.json`, `data/college.json`, `data/creditbank.json` 수정
2. `node scripts/build-data.mjs` 실행 → `js/data.js` 재생성
3. 커밋·푸시하면 GitHub Pages에 자동 반영

> 정보는 공개 자료를 정리한 참고용입니다. 지원 전 반드시 각 대학 모집요강을 확인하세요.
> 분석 점수는 반영비율과 공개 입결을 단순 비교한 참고 지표이며 합격을 보장하지 않습니다.
